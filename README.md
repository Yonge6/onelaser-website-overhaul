## 一、对标打分卡：怎样才算“超越”

| 维度 | OneLaser 现在 | xTool | Thunder | 我们的目标(2027-03) |
|---|---|---|---|---|
| 首页请求数 / 重量 | 559 个 / 9.6 MB | 500 / 13.5 MB | 129 / 2.1 MB | **≤120 个 / ≤2 MB**(比 Thunder 更轻) |
| 首页脚本数 / 第三方域名 | 118 / 38 | 249 / 64 | 60 / 26 | **≤40 / ≤15** |
| 字体 | 每页 7–9 个字体族 | 1 个 | 2 个 | **1 个(Certia)** |
| 标题字号 | H1 20–42px，XRF 页正文 16 种 | 统一 | 统一 | **按 UI-SPEC 一套阶梯，正文 ≤6 种** |
| 主力产品页 | XRF 22 个区块、约 7.8 万像素 | — | Nova Pro 12 个区块、约 6.1 万像素 | **≤12 个区块，≤5 万像素** |
| 选机工具 | 对比页 265 词，不在导航 | Help Me Choose | Help me choose + Compare | **对比 + 3 题选机 + 回本计算器**(两家都没有回本计算) |
| 打样 / 体验 | 有，但不在导航 | Product Demo | See one in person | **免费打样 + Demo 都进主导航和产品页** |
| 服务承诺 | 3-2-1 保修只在产品页写 | xToolCare | 2 年保修、全美技术员、免费培训 | **首页 4 个数字：3-2-1 保修、美国工程师、美仓 24 小时发货、打样 5–7 天** |
| 支持入口 | 散在 9 处 | 按产品线 | Support + 650+ 文章 | **1 个 Support Hub** |
| 内容 | 254 篇博客无分类，约 28 组重复 | 学习中心 + 项目库 | 67 节视频课 | **博客分类 + 主题簇合并；材料参数库可筛选；OneLaser Academy** |

*数据：2026-11-11 在浏览器里对三家首页用同一方法实测(加载后 6 秒)。Google PageSpeed 免费额度用完，移动端核心指标等额度恢复或接入 Search Console 后补测。*

### 我们能赢的地方(要在网站上讲透)
1. **桌面机用 RF 金属管**(XRF)，**工业机双光源**(Hydra Gen2 玻璃管 + RF)——这是 xTool 和 Thunder 都没有的产品组合，现在网站上没有讲成一条清晰主线。
2. **免费材料打样实验室**——两家导航里都没有，我们有却藏起来了。
3. **美国工程师 + 美仓 24 小时发货 + 3-2-1 保修**——要放到首页第一屏下方，而不是只在产品页深处。
4. **MakerBoost 自有软件**——现在只是一个孤立页面，应进导航并在产品页讲。

## 四、整改方案(五条工作线)

### 1. 修错与清理(P0/P1)
H1 错误、标题换行、缺失 Meta、错误链接、过期活动页、重复政策页、重复分类。→ 任务卡 A1–A4。

### 2. 品牌统一(P0)
一个字体家族、一套字号阶梯、两种按钮、行动红只用于按钮和价格；插件字体跟随主题。→ 任务卡 B1–B4。

### 3. 决策路径(P0，超越的关键)
- 主导航改为：Lasers / Compare & Choose / Industries / Accessories & Materials / Support / Learn / Offers；
- 新对比页：全系参数表 + 3 题选机(用途、幅面、预算) + **回本计算器**(每月订单数 × 单价 → 几个月回本)；
- 每个产品页固定出现：分期月供、免费打样、Demo、3-2-1 保修、美国工程师。

### 4. 产品页与首页(P1)
- 以 V4 原型和 UI-SPEC 为基础，出统一产品页模板(≤12 区块)，XRF 先行，再套 Cobra / Hydra / VertiGo；
- 首页讲清三条产品线 + 四个服务数字 + 打样 / Demo 入口；
- 性能：YouTube 点击后再加载、清理不用的插件、swiper 改为主题内置或固定版本(现在从 unpkg 拉 `swiper@8` 浮动版本)。

### 5. 内容与 SEO(P2)
- 博客加分类(选购 / 教程 / 故障 / 新闻)，约 28 组重复文章合并成主文 + 301；
- 材料参数库做成可按机型和材料筛选的页面；
- 行业页：标牌、个性化定制、杯具、教育、批量生产(ChatGPT 配图)；
- OneLaser Academy：先做 10 节按机型的上手视频课。
